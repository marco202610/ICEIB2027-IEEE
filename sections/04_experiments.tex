\section{Development Status and Evaluation Plan}\label{sec:experiments}
\subsection{Available Evidence}
The source development record reports 56 passing local and simulated tests: 37 for blockchain-related functions, 11 for assistant integration, four for the avatar and four for audio segmentation \cite{blockchain}. These results were not independently rerun for this paper and do not validate GPS trajectories, food MCP, real-device sensing, production cloud deployment, actual blockchain transactions or the integrated workflow.

\subsection{Planned Evaluation}
Table~\ref{tab:comparison} summarizes the proposed evaluation. Compare raw and quality-filtered positioning against measured reference routes and timed walking; report trajectory deviation, distance error, speed error, missing intervals and, where available, cadence error. Compare fixed and lower-load sampling on the same device and route, measuring data volume, battery change, elapsed time and missing-data rate. Report phone model, operating system, permissions, background restrictions and carrying position.

For GIS, compare straight-line and available route-network distances using verified POIs, and assess route suitability and user completion. For the avatar and food MCP, measure task completion, query success, confirmation and recording time using predefined tasks. Test authorized cloud uploads, digest verification and separate-consent handling; evaluate actual anchoring only after real transactions are enabled. Ground truth, sample size and statistical analysis must be specified before experiments.
